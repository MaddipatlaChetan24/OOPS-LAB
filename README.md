## Getting Started

### Clone the repository

```bash
git clone https://github.com/MaddipatlaChetan24/OOPS-LAB.git
```

### Open the project

Open the project in your preferred Java IDE.

Examples:

- IntelliJ IDEA
- Eclipse
- NetBeans
- VS Code

### Compile

```bash
javac ProgramName.java
```

### Run

```bash
java ProgramName
```

Example:

```bash
javac Armstrong.java
java Armstrong
```
